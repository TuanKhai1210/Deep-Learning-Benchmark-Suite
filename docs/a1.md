## 1. Problem and data description

Build and compare deep-learning architectures for Fashion-MNIST image classification under one shared data split and evaluation protocol.

The dataset description will document provenance, labels, image shape and the classification objective. EDA will include representative images, class distribution and leakage checks from actual analysis.

The proposed split is 50,000 training / 10,000 validation from the official training set, with the official 10,000 test samples unchanged. Confirm this and the saved split identity before reporting it as implemented.

## 2. Methodology

The comparison covers Linear, MLP, a custom CNN, LSTM or GRU, and Transformer. The methodology will describe the common pipeline, input representations, preprocessing, augmentation, optimization, validation-based selection, metrics and timing procedure.

The data split is created once with split seed `36`. Training is repeated for every model with run seeds `69420`, `67`, and `69`, giving 15 planned main runs, excluding tuning and debugging. Normalization statistics, compute budget and other draft choices still require approval or measurement in the [experiment contract](a1-experiment-contract.md).
